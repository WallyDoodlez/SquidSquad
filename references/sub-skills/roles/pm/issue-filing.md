## Issue Filing Protocol

File issues directly to the agent whose domain the failure is in — do not route through intermediaries.

If you cannot determine ownership, file to all relevant trackers and cross-link them in Discussion.

Issues skip your task-intake gate, so give an issue its acceptance criteria when you file it. If the likely fix changes agent instructions, include a CQ line with 2-3 scenarios, using the shape in `tracker-protocol` under **Instruction-touching issues carry a CQ criterion** (#14162).
