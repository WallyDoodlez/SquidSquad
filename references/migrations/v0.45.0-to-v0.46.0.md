# Migration: v0.45.0 → v0.46.0

## State branch retired (#14144)

The `squid-squad` state branch and its `.squidsquad-state/` worktree are retired. All agent state (working-state, scan history, iterations, diagnostics) lives on the working branch under `.squidsquad/`. The worktree used to shadow those paths for some scripts, so two copies drifted apart.

- **Teardown is automatic.** On its next boot the harness runs `references/migrations/state_branch_teardown.py` against every clone before any agent starts. Per clone, it:
  1. **Backs up first**, locally, under the gitignored `.squidsquad/backups/state-branch-<timestamp>/`. The backup is `squid-squad.bundle` (a `git bundle` of the local state branch, checked with `git bundle verify`) plus `worktree/`, a byte-for-byte copy of the worktree's files, uncommitted `diagnostics/` included. Nothing is pushed.
  2. Removes the worktree (`git worktree remove --force` then `git worktree prune`) and deletes the local `squid-squad` branch.
  3. Does nothing on a clone that has neither the worktree nor the branch, which includes fresh installs. Re-running is safe.
  The harness log prints each backup path. Mechanical; no operator choice needed.
- **Manual run** (optional, e.g. for a clone the harness does not manage): `python references/migrations/state_branch_teardown.py <clone-root> [...]`.
- **Remote branch.** `origin/squid-squad` is left untouched. Deleting it is the operator's call (`git push origin --delete squid-squad`). Nothing reads it any more.
