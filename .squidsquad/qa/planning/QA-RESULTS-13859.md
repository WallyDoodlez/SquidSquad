## Fix needed (specific, actionable)

Add `.squidsquad/vault/.telemetry/*.jsonl merge=union` to the root, already-tracked `.gitattributes` — directly alongside the existing `galaxy/*.md` / `areas/*.md` / `projects/*.md` union entries (same file, same pattern, zero new infrastructure). This is simpler and more robust than the current per-clone-local-file approach: it ships automatically to every clone via normal git clone/pull, requires no installer step, and closes the gap `wizard.py`'s local seed can't reach (a clone that never runs `install_vault_engine()` — e.g. a fresh `git clone` without the wizard, or CI). The existing local `.squidsquad/vault/.telemetry/.gitattributes` seed in `wizard.py` can stay as a redundant belt-and-suspenders local copy, or be removed once the tracked root entry covers it — either is fine.
