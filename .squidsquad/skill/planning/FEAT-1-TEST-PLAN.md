## Unit Tests (pytest) — Drift Prevention

### TC-20: All generated .sh scripts are identical except for ROLE value

**Precondition**: Boot scripts generated for all 3 roles.
**Steps**:
1. For each role, read `start-<role>.sh`.

3. Compare the normalized content across all 3 roles.
**Expected**: After role-name normalization, all 3 .sh files are character-identical.
**Verification**: `normalized = [content.replace(role, "__ROLE__") for role, content in scripts]; assert all(n == normalized[0] for n in normalized)`.

### TC-22: No role-specific logic leaks into generated .sh output

**Precondition**: Boot scripts generated for all 3 roles.
**Steps**:
1. For each role, read `start-<role>.sh`.
